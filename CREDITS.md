# Credits & Inspiration

career-radar is an **original** implementation. It was inspired by patterns from
the open-source project **career-ops** (https://github.com/santifer/career-ops,
MIT License) - specifically the *concepts* of:

- A-F multi-dimension scoring rubric
- User-Layer vs System-Layer data separation
- "modes" as reusable prompt playbooks
- Regional market calibration
- Voice/anti-AI-slop guardrails

No code was copied. These are re-implemented from scratch for a different niche:
**phone-first, cloud-run (GitHub Actions), LATAM->Europe relocation + Walmart
internal mobility.** This is not a fork.

UI direction was benchmarked against commercial apps like AIApply (aiapply.co)
for the dashboard / match-card / pipeline feel.

Thanks to the career-ops maintainers for the excellent open patterns.
